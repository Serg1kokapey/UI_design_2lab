Елемент #1

Radiobutton (Радіокнопка / Перемикач)

Призначення: Дозволяє користувачеві обрати лише один варіант із взаємовиключного набору опцій. При виборі нової радіокнопки попередній вибір у межах тієї ж групи автоматично знімається.

Приклад роботи:

Оберіть середовище для запуску тестів:

Обране середовище: Development (DEV)

Елемент #2

Checkbox (Прапорець / Чекбокс)

Призначення: Використовується для вибору нуля, одного або декількох незалежних варіантів зі списку, або для увімкнення/вимкнення певної окремої опції (наприклад, згода з умовами).

Приклад роботи:

Оберіть типи тестування для релізу:

Обрано (1): Smoke тестування

Елемент #3

Text input (Текстове поле вводу)

Призначення: Базовий елемент форми, який дозволяє користувачеві вводити та редагувати однорядкові текстові дані (ім'я, логін, пошуковий запит, email тощо) з клавіатури або з буфера обміну.

Приклад роботи:

Попередній перегляд: (порожньо) 0 / 60 символів
Елемент #4

Tabs (Вкладки)

Призначення: Організовують пов'язаний контент у декілька окремих розділів в одній області екрана. Дозволяють користувачеві швидко перемикатися між розділами без перезавантаження сторінки.

Приклад роботи:

Баг #104: Кнопка «Оформити замовлення» залишається неактивною після заповнення всіх обов'язкових полів форми доставки.
  1. Додати будь-який товар у кошик.
  2. Перейти на сторінку оформлення замовлення.
  3. Заповнити поля Ім'я, Телефон та Адреса валідними даними.
Кнопка «Оформити замовлення» стає активною (доступною для натискання) одразу після заповнення обов'язкових полів.
Елемент #5

Button (Кнопка)

Призначення: Інтерактивний елемент керування, який ініціює миттєву дію або подію при натисканні користувачем (наприклад, відправка форми, збереження даних, запуск процесу або очищення полів).

Приклад роботи:

Статус: Кнопку ще не натискали (0 разів).

Елемент #6

Text label (Текстова мітка / Підпис)

Призначення: Статичний текстовий підпис, програмно пов'язаний із конкретним елементом форми (через атрибут for). Пояснює, які саме дані потрібно ввести, а також покращує доступність (Accessibility): клік по мітці автоматично встановлює фокус у прив'язане поле або перемикає чекбокс.

Елемент #7

Link (Гіперпосилання)

Призначення: Елемент навігації (тег <a>), призначений для переходу користувача на іншу вебсторінку, зовнішній ресурс, завантаження файлу або переміщення до іншої секції поточної сторінки (якірне посилання).

Елемент #8

Tooltip (Спливаюча підказка)

Призначення: Невелике інформаційне вікно, яке з'являється при наведенні курсора миші (hover) або фокусі з клавіатури на елемент інтерфейсу. Надає коротке додаткове пояснення без захаращення основного екрана.

Приклад роботи (наведіть курсор на іконку або кнопку):

Blocker (Блокер): Критична помилка, яка блокує подальше тестування або роботу ключового функціоналу системи.
Текст із нативним атрибутом title (затримайте курсор)
Елемент #9

Dropdown list (Випадаючий список)

Призначення: Компактний елемент вибору, який у згорнутому стані займає лише один рядок, а при натисканні розгортає список доступних опцій. Заощаджує місце на екрані, коли варіантів вибору більше ніж 4–5.

Приклад роботи:

Обране значення: S2 - Major (Значна)

Елемент #10

Data grid (Таблиця даних)

Призначення: Відображає структуровані однотипні дані у вигляді рядків та стовпців. На відміну від простої статичної таблиці, Data Grid зазвичай підтримує додаткові можливості: сортування за стовпцями, фільтрацію, пошук або пагінацію.
